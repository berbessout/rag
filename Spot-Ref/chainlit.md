# 🔍 Spot-Ref Assistant - Document Search & Analysis

Welcome to **Spot-Ref Assistant**, your intelligent document search and analysis tool!

## 📚 Features

- **Vector Document Database**: Powered by Qdrant for precise semantic search
- **Hybrid RAG Architecture**: Combines metadata filtering with vectorial search
- **Real-time Architecture Switching**: Choose between different search strategies

## 🚀 Getting Started

Ask questions about projects, technologies, clients, or any information in our document database.

**Example questions:**
- "Find me Python projects for Air Liquide"
- "What are the banking projects in France?"
- "Show me Azure references"
- "Cloud migration projects for European clients"

Start chatting to begin your search!
